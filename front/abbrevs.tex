% Notation and abbreviations for the thesis.
%
% Abbreviations use \newacronym[category=notation-category]{key}{SHORT}{long};
% instruction mnemonics use \newglossaryentry{key}{type=notation,
% category=notation-category, name=..., description=..., sort=...}. The notation
% category and the \keepUnusedAbbreviations call at the bottom make every entry
% appear, whether or not it is \gls-referenced in the body. Requires
% glossaries-extra (loaded unless the noabbrevs option).
%
% Acronym expansions are written in title case (e.g. "Branch Target Buffer").
% Entries whose "meaning" is a descriptive phrase rather than a word-for-word
% expansion (AArch64, QARMA, FEAT_CSV2, FEAT_FPAC, CT-SEQ, the trace terms) stay
% in sentence case; the list style capitalises their first letter.
%
% The formal mathematical notation (P, I, C, HTrace, O, Attack_O, run, Q,
% HTrace^Q, IS, lanes, splice, r(t), t_max, etc.) is intentionally NOT listed
% here: each symbol is defined in place where it is introduced in the body.
